# 敗北の比較と応用テクニック（2026-09-14）

敗北後の選択肢に「ライバルの会話・スコアを見る」「次の対策を沙織に聞く」を追加。既存のスクロール観測画面を再利用し、閉じると結果の選択肢に戻る。再挑戦・終了の選択肢も維持。

比較では現選考の生存者＋今回の脱落者を選考スコア順に表示。好感度、支持数と換算値、つながり、相互理解、最低生存スコアとの差と同点敗北を説明。相互理解は選考への直接加算ではない。ストレスや危険札による敗北は実際の理由も冒頭に表示。

communicationMechanicsのライバル加点時に、本人の発言・恋愛対象の返答・会話技法・好感度増分・相互理解増分を記録。既存の乱数、好感度9〜14増加、支持の計算は変更しない。相互理解は深く聞く／未来を広げる会話+2、他+1（上限100）。相互理解によるライバル得点加算はない。
会話は進行時にルールで生成される定型文。話題、ターン、相手の配役、ライバルの職業で変化する。AIによる会話の意味採点はしていない。敗北後に架空の過去会話を生成して帳尻を合わせない。
全員分を周・章・時間軸・ターン付きで保存。旧セーブにない詳細と相互理解は未記録と表示。既存npcSceneがあれば直近の観測記録として別途表示。巻き戻し前の会話を現在の比較に混ぜない。

沙織の対策は既存PythonAPIへ実スコア・記録・習得テクを渡し、セリフ例を提案する。AIに得点・勝敗・報酬を変更させない。JSON hintと通常の文章を受け付け、600字超や不正形式・通信失敗は定型助言に代替。追加AIポイント消費なし。ネット検索は行わない。
