# 記憶UIとタイムリープ改修（2026-09-14）

## 操作
「記憶・話題」を開くと、話題の語句＋関係する相手の発言の短い抜粋を1行ずつ表示する。スクロールして最大2件をクリック選択、再クリックで解除。A/B・前/次の操作は廃止。
「話す内容を作る」は集中1で候補を追加。「AIで話を広げる」は1 AI（能力補正あり）で「深く知る」目的の候補を生成。実際に候補を選んで話すと効果が発生する。
右上の記憶ボタンと会話準備パネルは領域を分離。

## 記憶と巻き戻し
今回の時間で交わした記憶は1件+4、2件+7。前の周または巻き戻し前の記憶を含むと1件+6、2件+10。好感度の通常計算に加算され、上限・場面補正は別途適用。
同じ記憶の組み合わせ・同じ目的では、同一時間内に追加ボーナスを再取得できない。逆順も同じ組。1件につき新しい角度は3回まで。巻き戻し後は再挑戦できる。
相互理解は通常+1、記憶1件の新しい角度+4、2件+6（置換、重複加算なし）。
会話原文・表示ログを巻き戻しとセーブ／再開で保持。過去はプレイヤーの知識であり、NPCが覚えている共有会話とは区別する。AIにも「以前話した」と言わず初めての質問にする旨を渡す。開始とタイムリープ後に使い方を案内。

## ログの混入原因
従来の内部進行ログには自動記録した人物設定や、画面と別の実況文が入っていた。表示専用presentedLogを追加し、画面の地の文・会話と選択して話した発言だけを記録する。更新時の同一文は重複させない。
旧内部ログはゲーム処理用に保持するが、画面のログには移さない。旧セーブの閲覧ログは修正後の表示分から蓄積する。

## AIが利用できない場合
- 操作できない：処理中、AI不足、そのターンで使用済み、未完了の生成など。ボタンに状態を表示。
- 応答が届いたのに不採用：JSON、文字数、話題語、会話目的、選択した両方の記憶の語句の検証。実通信で「深く知る」なのに誘い・共通点の返答になるケースを再現した。
- line上限80→140字。目的に合う具体的な質問をシステム指示にし、再試行時に不採用理由を渡す。最大1回の再試行。失敗時はローカル候補で続行し、話題・察知のAI消費を返す。通常会話の返答はAI資源を消費しない。
- HTTP等の通信障害と形式不一致を案内文で区別。詳細はLastAIError。
- AGI上限が12なのに再開時8超を拒否する旧検証も12へ修正。

## 攻略と確率（現在のコード）
最初の脱落は導入の固定展開。通常の脱落判定は好感度＋支持数/5000（整数）＋つながりの合計が最低の人。同点はプレイヤーが先に脱落する。
名前を覚えて呼ぶと+2、名前呼び単体と褒め行動は+3。好みの話し方や記憶を組み合わせ、相手の返答を次の会話に使う。
通常会話は一律の成功抽選ではなく状態・行動による点数計算。褒める成功率は55＋min(30,好感度/2)％。ドキッとさせる行動はmin(90,30＋周×15＋min(20,好感度/3))％、対応するAI行動は2 AIでその行動の成功を保証（ゲーム全体の勝利保証ではない）。
AI文面が点数や勝敗を直接決めるわけではない。全体勝率はプレイ方針とライバルの進行に依存し、今回の改修後の統計的な勝率は未測定。過去READMEの30シード結果は旧バランスの最適操作テスト。

## 検証
Unity 6000.3.19f1でコンパイル成功。15項目のルール検証（巻き戻し、保存、重複・逆順ボーナス、消費など）成功。
実Canvasで20行スクロール、2件選択、3件目防止、A/B・前/次廃止、重なり防止、候補作成、内部ログ非表示を確認。
実PythonAPIで2記憶の話題生成成功。修正前には目的不一致→ローカル代替も再現。Console error 0。
テストはsaveEnabled=falseで実施。添付スクリプトの記憶は検証用データで、ユーザーセーブには書き込まない。

## 追加：沙織から会話テクニックを習得
無料アドバイスと「気持ちを察知」で、恋愛対象別の選択肢を解放する。最初は1件、対象との会話記憶2件ごとに解放可能数が1件増える（最大4件）。相談1回で1件習得。連打しても進行条件を超えて取得できない。
ひかり：髪型 → ネイル → 服の素材 → おしゃれの工夫。
悠斗：服のこだわり → 写真とカメラ → ゲーム制作の工夫 → 車と出かけ方。
見えないネイルの色、車の所有や車種は断定しない。本人の選び方や工夫を具体的に尋ねる。
習得時は「次へ」を経て、テク名付きの発言候補を表示。基礎Power6に、各テク初回だけ+6（通常の場面補正あり）。発言したときだけ使用済みにする。2回目以降も使えるが初回加算なし。
習得・使用済み履歴はセーブ、次の周、タイムリープ後も保持する。巻き戻しで初回ボーナスを再取得できない。
AIが使えない場合も各テク専用の相手の返答を用意。男女各12項目、計24項目のルール検証成功。Unityコンパイル成功。通常の会話UIを再利用、追加アセット設定不要。
