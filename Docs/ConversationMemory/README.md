# 会話の記憶とAI話題（2026-09-13）

カード撤去・Reward/Archetypeを経由しない章送り・自己紹介AI・男女配役・割り込み実装を保持した、コミュニケーション中心の試作。

## 遊び方

1. 相手と話すと、自分の発言と相手の返答が「ふたりの記憶」に対で残る。
2. 上部右のボタンで記憶を開く。「話の種 A」、必要なら別の「結ぶ記憶 B」を選ぶ。
3. 閉じて「話題を作る」。目的は「深く知る」「自分も伝える」「一緒の未来」。AIが選択した会話を使って一言を生成する。
4. 新しい選択肢には記憶の効果を予告。実際に発言すると相手が答え、新しい記憶が残る。
5. AIを使わず「この記憶から話す」でも会話をつなげられる（集中1）。

話題生成と気持ちの察知以外のAIボタンは一時非表示。旧処理・カード関連APIは残す。AI準備→発言の2段階、1ターンにつき話題生成1回・察知1回。どちらもAI1を消費。気持ちは直前の発言を根拠にした推測で、勝敗を決める機能ではない。

## ルールと保存

- 会話1件につき相互理解+1。新しい記憶の角度では好感度に+4、相互理解+4。2つの記憶をつなぐと好感度に+7、相互理解+6（通常+1との重複加算なし）。好感度は既存の上限・場面補正も受ける。
- 同じ記憶・同じ目的の再使用はシナジー0。同じ組を逆順にしても同一扱い。各記憶は3回まで新しいシナジーに使える。2件目に回して上限を迂回することもできない。
- 相互理解は最大100。最終章では12ごとに発言の好感度+1。
- 生成しただけで未発言の話題は、共有記憶に追加しない。相手の返答に書かれた言葉だけを話題として受け取る既存の検証を維持。
- 記憶は相手ID・周・章・ターン・双方の原文を保存。同じ周の章移動とセーブ／再開で保持。過去の周の記録自体は残すが、相手が覚えている記憶として選択できない。
- セーブに新規フィールドを追加。旧セーブも空の記憶から再開可能。空のarchetypeを理由に旧選択画面へ戻す不具合も修正。
- 本編だけcommunicationMechanicsを有効にし、ライバルも会話で好感度を得る。旧カード補正をプレイヤーだけ失う不均衡を解消。カードモードの従来NPC処理は保持。

## AIと制約

既存PythonAPIの/api/chatを使用。話題ではキャラ設定、選んだ2件の会話原文、目的を渡す。選択した記憶の語を無視した回答、目的を示す表現がない回答（理由の質問／自分を主語にした発言／一緒の行動）、形式不正、長すぎる回答は採用しない。再生成は1回までで、AIポイントの追加消費なし。それでも失敗したら目的・選択記憶に基づくローカル文を表示する。点数はAIに決めさせない。

シナジーは「共有した会話を明示的に選択し、新しい目的で使ったか」という決定論的ルール。意味の深さをLLMが採点しているわけではない。自由入力の意味評価、相手の長期的人格変化、全新規文言の英訳は未実装。

## 検証

- `rules-verification.txt`：Unity上の実ShowGameを使った保存・二重消費・未発言・再使用・逆順ペア・周巻き戻し検証と30シード×3方針。
- `play-verification.txt`：実際のButton/ChoiceMenu、モーダル中の発言防止、目的選択、生成、返答、気持ち察知、専用一時ファイルへの保存／再開。通信成功とフォールバックを区別して記録。
- `purposes-and-raycast.txt`：同じ記憶で3目的を生成し、目的に対応した文になることと上部・記憶選択・閉じるボタンの実レイキャストを確認。
- `full-play-runs.txt`：2回の3章Play。各章で実APIの話題生成と返答を使用し、それ以外はローカル返答。最適なPowerの選択肢を選ぶ自動操作なので、初心者の勝率・主観的な面白さの評価とは異なる。
- `03-shared-memories.png`、`04-group-topics.png`、`05-result.png`：実Game ViewのUI。

繰り返しの調整後、30シードで通常選択のみ0/30、1件の記憶を使う方針28/30、2件とAI目的を使う方針30/30。記憶を使う意義は確認できる一方、最適操作には易しい初期バランス。数値だけでなく、生成された一言から相手が具体的な話を返すかを実通信で確認した。

## 実装

- `ShowConversationMemory.cs` / `ShowState.cs`：会話記憶、目的、シナジー、相互理解。
- `MansionMemoryJournal.cs`：既存Canvas/フォントを使うRuntime生成ウィンドウ。原文はスクロール可能。
- `MansionSignalDirector.cs`：2能力のUI・非同期生成・保存。
- `MansionSignalView.cs`：長い選択肢の可変高さ・スクロール。
- `ShowDialogue.cs`：現在の周で実際に交わした会話をAIへ渡す。
- `AuditionSceneBridge.cs`：空テキストを名前置換するときのNullReferenceを防止。

シーン／Prefabの再セットアップ不要。テストは本編セーブ無効、保存確認はTemp/ConversationMemoryCheck.jsonのみ。コミットは行わない。
