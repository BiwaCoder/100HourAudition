# RealtimeVoice terminal UI

2026-09-12。RealtimeVoiceTestの既存uGUIを更新。

- 黒い微細ノイズ、白文字、枠線ボタン。
- AI再生音は青、入力音は赤、文字起こし受信後のAI再生音は紫。
- 文字演出はタイプライター→ノイズ復号→広がった復号帯。生成中は小さな光と短い言葉で、生命の誕生を控えめに暗喩。
- 音声送信と生成APIの仕様は変更していません。

## 検証画面

01: 待機 / 02: 青いAI出力 / 03: 赤いユーザー入力 / 04: 紫のAI出力 / 05: 生成中 / 06: 完成。

画面確認は外部API・実マイクを使わず、合成PCMを既存再生プレイヤーと入力解析バッファに与えて実施。キャラクターJSONと文字起こしもテストデータです。ScreenCaptureでCanvasを含めて保存。実際の会話音声による確認は今回未実施です。

`offline-checks.txt` は各撮影時のRMS、FFTの最大値、実描画メッシュの頂点数、色、接続・マイク状態。解析の単体チェックと状態・JSONコピーのPlayチェックは `RealtimeVoiceTerminalChecks.Run()`。

開始ボタンを押すまで外部通信・録音は始まりません。生成中は既存ControllerがDisconnectし、中止・Play終了でもマイクと接続を閉じます。
