# 序盤〜タイムリープ後 シナリオ台本(現状)

SeasideMansion(3D版)の実際の表示テキストをコードから書き出したもの。修正するときは各見出しの「変更箇所」を編集する。

対象コード:
- `Assets/Scripts/Environments/SeasideMansion/Runtime/MansionArrivalDirector.cs`(到着カットシーン)
- `Assets/Scripts/Environments/SeasideMansion/Runtime/MansionSignalDirector.cs`(番組本編・UI表示テキスト・沙織の開眼演出・チュートリアル)
- `Assets/Scripts/RealityShow/Runtime/ShowGame.cs`(ルール本体・ログ用セリフ)
- `Assets/Scripts/RealityShow/Runtime/ShowSupportVoice.cs`(沙織の定型セリフ)
- `Assets/Scenes/GameScene/SeasideMansion.unity`(カットシーンのキャプション文言)

---

## 全体の流れ

```
[イントロカットシーン] → [自由探索] → [悠斗と接近→出会い演出]
  → 番組開始 → 自己紹介の選択 → 第一関門(審査) → 第一の脱落
  → 沙織の開眼(全7ページ) → タイムリープ発生
  → チュートリアル(未来観測を強制的に1回使わせる)
  → 通常運用(章0のRoute選択へ)
```

## 2. 自由探索 → 出会い

プレイヤーが悠斗(`counterpart`)に一定距離(`encounterDistance`、既定3m)まで近づくと発生。

**変更箇所**: 同シーンの `Encounter Caption` フィールド。

> **FIRST CONTACT / 認識できない相手**
> いま、新たな物語が始まる。
> 緊張で、相手の表情がうまく読み取れない。

この後 `firstEncounter` カットシーンが再生され、番組本編(Exploration)へ移る。

## 3. 番組開始(BeginEncounter)

**変更箇所**: `ShowGame.Begin()` (ShowGame.cs 22-26行目)

> 地の文(番組ログ): 100時間。四人の参加者と、一人のクリエイター。ここから、あなたの物語が始まる。

⚠️ **実装上の注意**: `Opening`フェーズ(3ページ)は `BeginEncounter()` 内の `while(Game.State.phase==ShowPhase.Opening)Game.Advance();` で自動的に3ページ分スキップされ、3D版では画面に一切表示されない(2D版`ShowController`には表示ロジックがあるが、3D版は使っていない)。ここに演出を足したい場合は `MansionSignalDirector.Refresh()` の `switch(s.phase)` に `ShowPhase.Opening` のケースを追加する必要がある。

## 8. タイムリープ後 = チュートリアル(Tutorial 1〜3)

**変更箇所**: `MansionSignalDirector.cs` 各所(`Tutorial`変数、133-145行目・181-190行目)

タイムリープ直後、`Tutorial=1`の間は次の制約がかかる。

1. **Route選択画面**の案内文が特別版になる:
   > さきほどの脱落は、計算の中にあります。
   > 今度は場所を選び、未来観測を試してみましょう。
2. Routeを選んで会話(Conversation)が始まると、**会話の選択肢を選べず**、右側の「未来観測」以外操作できない。案内文:
   > 沙織：右の「未来観測」を押してみてください。発言せずに候補を比較できます。
3. 「未来観測」を一度使うと、**このときだけAGI+6の実習補給**が入り、`Tutorial=2`に進む(他の能力もここで初めて使えるようになる):
   > 観測実習：まだ発言も時間も進んでいません。［予測］と他の候補を比較して、あなたの言葉を選んでください。
   > 実習補給 +6 AGI（今回のみ）。
4. `Tutorial=2`の間、会話画面には毎回一言添えられる:
   > 沙織：印は予測です。納得できる言葉を選んでください。
5. プレイヤーが最初の発言を選ぶと `Tutorial=3`(通常運用)になり、以後この制約は外れる。

**通常運用時のRoute案内文**(Tutorial解除後、毎回表示):
> 同じ邸宅。同じ出会い。けれど、あなたには記憶がある。
> どこで、次の言葉を交わしますか？

## 9. 最初に使える能力(沙織のAIスキル)一覧

タイムリープ後、会話中に画面右のツールパネルから使える。表示ラベルと消費AGIは実装(`MansionSignalDirector.Refresh()` 197行目)のまま。

| 表示名 | 消費AGI | コード上の名前 | 効果 |
|---|---|---|---|
| 未来観測 | 2 | `Forecast()` | 現在の会話選択肢のうち最も効果的なものに［予測］印を付け、危険な発言(告白・賭け系カード)の条件未達も警告する |
| 他人の視点 | 1 | `UsePerspective()` | 相手が今どんな話し方(創作/共感/公開)を望んでいるかを1ターンに1回だけ教える |
| 偶然の発動 | 2 | `SetWeather()` | 場の天候(晴れ/雨/風/霧/停電)を変える。選ぶと専用のサブ画面が開く |
| 新しいカード | 1 | `Acquire()` | 3枚の候補から1枚をデッキに加えるドラフトを1ターンに1回起動 |
| タイムリープ | 3 | `TimeLeap()` | 章の入口まで時間を戻す。デッキ・記憶・同調Lvは保持、AGI消費は戻らない |
| 能力について | 0 | — | 説明文を表示するだけ(AGI消費なし) |

**「偶然の発動」を選んだときのサブ選択肢**(`ShowWeatherChoices()`):
晴れ / 雨 / 風 / 霧 / 停電(いずれもAGI2) / 戻る

**初期リソース**:
- AGI初期値: Easy/Normal = 4、Hard = 3(2周目以降は前回の残りが一部繰り越される、上限8)
- 集中力(focus): 毎ターン3にリセット

## 10. 初期デッキ(8枚)

タイムリープ発生時(`ShowGame.Advance()`のAwakeningケース)に設定される最初のデッキ。

`listen`(静かな紅茶)×2 / `story`(物語の糸) / `purity`(純粋さのかけら) / `rain`(雨宿りの約束) / `draw`(好奇心の窓) / `rest`(深呼吸) / `memory`(記憶の栞)

※ `echo`・`spotlight`・`wind`・`confess`・`blackout`の5種は初期デッキには含まれず、章クリア報酬のドラフトでのみ入手できる。
