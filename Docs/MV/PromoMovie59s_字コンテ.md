# 100 Hour Audition — 59秒プロモムービー 字コンテ (v1)

- 尺: 59秒 / 1920x1080 / 24fps / 2.35:1 レターボックス(上下黒帯)
- 色: シネマティック。海と邸宅は「夕暮れの金 × 深い紺(ティール&オレンジ)」、UI画面は少し彩度を落として統一、暗部を持ち上げて柔らかく。全体に薄いフィルムグレイン、四隅にビネット
- 音楽: Seaside Mansion ジャズバラードの59秒編集版。メロディはミュート・トランペット(フリューゲルホーン寄りの柔らかい音)、ピアノ・ウッドベース・ブラシで支える。テンポ66 → 1小節 ≒ 3.6秒、16小節で約58秒
- テロップ: 日本語メイン + 英語サブ(小さく)。フォントはセリフ体(タイトルと同じ系統)。すべてフェードイン0.4秒 / フェードアウト0.4秒、必要な箇所だけ横スライドイン
- ナレーションなし(音楽とテロップだけで伝える)

## 制作手順(予定)

1. 音楽: 59秒版のMIDIを生成(トランペット主旋律、ピアノ伴奏) → GarageBandでMP3/AIFF書き出し
2. 映像素材: 邸宅の回り込みをUnityで録画(または既存スクショ)
3. 合成: ffmpeg で連番/静止画のケン・バーンズ、テロップのフェード、レターボックス、カラーグレード(LUT代替のカーブ)、グレインを一括レンダリング
4. 確認 → テロップや尺の微調整 → 最終書き出し(mp4, H.264, AAC)
