## Blender内の構成

- Blender 4.2.4 LTS。Z-up、正面-Y、メートル。通常2体は約1.85m、アニメ版は約1.72m。
- `CHARACTER - export this collection`: `Himari_Rig`、本体メッシュ、ワイヤー版のみ発光線メッシュ。
- 25ボーン。胴体・腕・肘・手・脚・膝・足、長髪3本、スカート4方向。通常のポリゴンと頂点グループなのでEdit/Poseモードで編集可能。
- `Himari_Idle`: 1〜97フレーム、24fps。待機と髪・スカートの微動。
- `Himari_WalkPreview`: 1〜33フレーム。短い歩行確認用。Action Editorで選択。
- ワイヤーの発光は4D NoiseのWをフレームで動かすドライバー。再生時に部分的に強さが変わります。
- 本体は1マテリアル＋頂点カラー属性 `Color`。元の色分け領域は面属性 `DesignRegion`、対応表は本体カスタムプロパティ `DesignRegion_palette` に保持。必要に応じてVertex Paintで編集。
- `PREVIEW_Outline`: Blender表示用の輪郭シェル。FBXには含めません。
- `STUDIO - preview only`: カメラ・床・ライト。ゲーム用の出力には含めません。

## Unity用の準備

同名の `.fbx` を3つ書き出し済み。リグ・頂点カラー・待機/歩行アクションを含みます。2026-09-12にテスト用SeasideMansionへインポート済みです。

Blenderのセル陰影ノード、輪郭シェル、発光のノイズドライバーはFBXだけではUnityへ再現されません。Unityでは頂点カラー対応セルシェーダーと発光シェーダーを割り当てています。25ボーンの待機／歩行はLegacy Animationでクロスフェードし、移動速度に追従します。

接地IK・布物理・表情・口パクは未実装。歩行はモデル変形を確認するための簡易アニメーションです。Editorで導入から操作開始、6表示の切り替え、移動・停止、コライダー維持を確認済み。実機性能検証は未実施。

役割変更の対応は `integration-plan.json`。既存男性側アセットは変更も削除もしていません。

## 検証と画像

`Verification.json`: 3 blend再オープン、全頂点のウェイト合計、骨参照、5歩行ポーズの有限座標・範囲、FBX再インポート、リグ/2アクション/頂点カラーの存在。
`Himari-ThreeStyles.png`: 3体比較。左からワイヤー／ストリート／アニメ。
`*-front.png`, `*-back.png`, `*-walk.png`: 実モデルをBlenderで描画。
`Himari-Wire-light-1.png`, `Himari-Wire-light-49.png`: 姿勢固定、発光だけを変えた比較。

再生成は `build_models.py -- street` / `-- anime` / `-- wire` をBlenderのbackground Pythonで実行。編集したblendを上書きするため、手作業で修正したら別版として保存してから使用してください。`palette.py` は頂点カラー統合、`verify_models.py` は検証、`render_comparison.py` は比較レンダー。
