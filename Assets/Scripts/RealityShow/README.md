# 100Hour Audition — 会話と記憶のリアリティーショー

## 始め方

`Assets/Scenes/GameScene/RealityShowGame.unity` を開いてPlay。
「新しく始める」からオープニングへ。「続きから」は最後に確定した状態を復元します。

- Easy：周回無制限。Normal：5周。Hard：3周、ライバルの会話と緊張が強くなる。
- 初回脱落は一度だけの物語上の演出。アリア覚醒後の周回数には含まれません。
- 自己紹介 → グループデート → 一対一。各章4回の会話を終えると1人が脱落。
- 各章の開始時に場所を選びます。会話のテーマ、相手の望む話、同盟を結ぶ相手が変わります。
- 最後まで残れば当選。脱落時は自分で「もう一度」か「降りる」を選びます。

## 会話の遊び方

1. 相手の返答と、右側の「いまの動機」を読む。
2. 手札をクリックして会話を支える効果を準備する。集中力は毎回3、AGIエナジーとは別。
3. 必要なら記憶を選び「尋ねる」「伝える」を押す。集中力1で新しい一言が生まれる。
4. 下の選択枠から実際に話す言葉を選ぶ。クリック、または上下キー＋Enterで決定。
5. 返答から次の話題を知る。手札は捨て札へ移り、次の4枚を引く。山札が尽きたら捨て札をシャッフル。

「結ぶ」は一度記憶から言葉を作ると解放されます。二つの記憶を選んで使います。
手札に集中力を全部使うと、その回は記憶からの言葉作りができません。
会話の選択肢そのものは集中力0でも選べます。

記憶を初めて会話に使うと信頼+4。繰り返し使うと補正は減少します。
会話で使った記憶から専用の**記憶カード**が見つかり、次の草稿の1枠に現れます。
そのカードと対応する記憶の一言を組み合わせると信頼+10。
同じ相手への別の話は+3、別の相手なら+1です。

たとえば「雨音の記憶」を聞く → 記憶×尋ねるで詳しく聞く → 草稿で「雨音の記憶の余韻」を獲得 → 次の会話でそのカードを準備し、雨音の話を重ねる、という流れになります。
カード名は元の記憶の長さに応じて短縮されます。

## 番組の判定

- 選考値 = 信頼 + スター数 / 5000（切り捨て） + 同盟。
- 最下位が脱落。同点はひまりが不利。
- カメラ向けの発言はスターが多く、相手に合わせた話と創作の話は信頼を得やすい。
- グループの散歩では生存中の参加者と会話し、同盟を得る。悠斗と話す場合の半分（切り上げ）の信頼も得る。
- 緊張100でその周は脱落。深呼吸と静かな紅茶で管理する。
- 各発言で番組時間が8時間進む。時計は実時間タイマーではなく、100時間の物語進行表示。
- 周回でデッキ・記憶・同調・未使用AGIの貯蓄を保持。信頼・支持・同盟・緊張・純粋さ・棘・残り時間を戻す。
- 貯蓄上限24、AGI上限8。周の開始時に基礎4（Hardは3）＋必要分の貯蓄を消費。
- 過去の周の記憶は相手は知りません。その記憶から作る一言は初めての質問として表現します。

## AGI

| 能力 | 消費 | 働き |
|---|---:|---|
| 他人の視点 | 1 | この場で相手が求めていることを読む。1発言に1回 |
| 未来観測 | 2 | 現在の手札・記憶・天候で強い一言を1つ表示。危険札の条件未達も警告 |
| 偶然の発動 | 2 | 晴れ／雨／風／霧／停電。次の発言まで有効 |
| カード取得 | 1 | 草稿3枚から1枚を山札へ。1発言に1回 |

雨は「雨宿りの約束」、風は「風のリボン」、停電は「闇の賭け」と相乗効果。
霧は緊張の圧力−3、ただしカメラ向け発言の追加スターが6000から3000へ減ります。
「禁断の告白」は信頼35以上か純粋さ2以上が条件。「闇の賭け」は停電が条件。
条件を満たさず話すと脱落します。Normal/Hardは棘3以上の失敗で再周回できません。

## AI会話

初期設定は**ローカル会話**。APIがなくても全編遊べます。開始時の乱数、相手、会話の選択、記憶、手札と草稿によって展開が変わります。

タイトルの「AI会話」をONにすると、既存 `ChatApiClient` を使って `http://127.0.0.1:8001/api/chat` に問い合わせます。
API呼び出しは発言を確定したときだけ。既存のPythonAPIの設定が使われます。
会話履歴、キャラクター、関係、現在の記憶、過去の周との区別、動機、最後の一言を送ります。相手の質問に答える次の一言も生成候補になります。
台詞に実際に含まれる話題・事実だけを記憶に採用します。勝敗・数値・デッキ操作はC#で決定します。
通信失敗や不正な応答は、同じ状態のローカル会話に切り替えます。AI設定はランのセーブには含めません。

## 既存UIと構成

`Assets/RealityShow/UI/RealityShowUI.prefab` が画面一式です。
Canvas（1920×1080基準）とEventSystemのある別シーンに配置できます。
シーンのビルド設定や既存NatureStage、NatureCutsceneLabは変更していません。

- **再利用**：ParticipantCard（写真・グレーアウト・OUT・スター）、ChoiceMenu（Shiro由来の選択枠）、AuditionTitle / Description / Clock、TimelineFeed（フェード式ページ送り）、GlassSurfaceGraphic。
- **ShowContent.asset**：人物・画像・基本カードをInspectorで設定。人物ID・基本カードIDはルールの識別子です。削除や変更ではなく画像・表示名・説明・話題を調整してください。
- **ShowGame / ShowState**：進行、デッキ、記憶、能力、選考、保存可能な乱数状態。
- **ShowDialogue**：ローカル会話、AIへの文脈、応答の検証。
- **ShowController**：入力、非同期通信、フェード、セーブの調停。
- **ShowView**：既存UIへの表示、ボタンイベント。
- **Fonts**：既存の日本語フォントを本機能用に分離。動的フォールバックは1024の複数アトラス、ビルド時の動的データ消去を有効化。
- **ShowSaveStore**：`Application.persistentDataPath/RealityShowRun-v1.json`。直前の保存は`.bak`。
- **Editor/RealityShowBuilder**：Unity APIでPrefabとシーンを生成。既存のシーンは上書きしない。

参考元：GrokProtoの番組進行・AGI・カードと天候、MemoryDeckSampleの会話の蓄積・動機・記憶×動詞・記憶同士の合成・初回想起・話題の更新。
写真はGrokProtoの`static/img`から、この機能のArtフォルダへコピーしました。
数値・カード使用方式・時間配分はUnity版の会話用に調整しています。元実装の完全な互換移植ではありません。

## 検証

`ShowRulesChecks.Run()`：会話解放、記憶合成、専用カード生成、重複除外、危険札、天候、資源制限、周回上限、保存と乱数継続、複数シードの完走。
`Checks~/VerifyPlay.cs`：Unity PlayでUIボタンからオープニング・脱落・覚醒・会話・記憶合成・草稿・再開・放送ページ送り・最終選考まで検証。AI発言を1回含むため、実行時は既存PythonAPIが必要です。

これは独立シーンで一周遊べる実装です。3D人物の芝居、音声収録、自由文入力、各カードの専用アニメーションは含みません。

お助けAIの口調・プロフィールは [Cinema/SAORI.md](Cinema/SAORI.md)。沙織は丁寧で少し照れ屋のご相談係として、導入と能力使用時にコミカルな敬語で話します。

### 通信ログと沙織の支援表示

Unity Consoleで `AIChat:` を検索すると、同じIDのREQUEST／RESPONSEを対にして確認できます。REQUESTにはmessageとsystem_message、RESPONSEには返答の原文・HTTPコード・通信結果が出ます。ShowControllerは採用結果とローカル代替への切り替え理由を `RealityShow AI` で記録します。ChatApiClientのInspectorでLog Requests And ResponsesをOFFにすると通信内容の出力を止められます。

沙織が能力を使うと、会話欄の先頭に「沙織のサポート」として地の文を表示します。支援の内容、場や選択への効果、AGI消費が分かり、放送ログにも残ります。API待機・正常受信・ローカル代替も区別して説明します。
